## 2. Разворот массива на месте
Обмен элементов `a[i]` и `a[n - 1 - i]`.

* **Трассировка по шагам ($i$ от 0 до $\lfloor n/2 \rfloor - 1$):**
  * **$i = 0$:** Меняем местами `a[0]` (4) и `a[4]` (9). Массив становится: `{9, 1, 7, 3, 4}`.
  * **$i = 1$:** Меняем местами `a[1]` (1) и `a[3]` (3). Массив становится: `{9, 3, 7, 1, 4}`.
  * При $i = 2$ цикл завершается, так как условие `i < 5 / 2` (то есть `i < 2`) становится ложным.

* **Сколько обменов выполнено?** 
  Выполнено **2** обмена.

* **Почему цикл идёт только до `n / 2`?** 
  Цикл идет до середины массива ($n / 2$), потому что на каждой итерации мы меняем местами сразу пару элементов (симметричных относительно центра). Если бы мы продолжили цикл до конца массива ($n$), то во второй половине мы бы поменяли эти же пары обратно, и массив вернулся бы в исходное состояние. Проход до середины гарантирует, что перестановка произойдет ровно один раз.

## 3. Ошибка в поиске минимума при инициализации `min = 0`

  Пусть массив состоит из положительных чисел, например: `a = {5, 2, 8}`.
